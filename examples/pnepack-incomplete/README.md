# 穴開き P.N.E. パックのサンプル

このフォルダは、作者が作成した台本に、別の参加者が音声・SE・差し絵を追加するための最小例です。

## 使い方

1. `pne_statekit_pack.json`をTauriの制作画面で開く
2. `assets/voice/`、`assets/se/`、`assets/image/`へ素材を追加する
3. `プロジェクトを検証`を実行する
4. 不足素材がなくなったら`.pneにパッキング`を実行する

このサンプルは意図的に差し絵が不足しています。そのままでは編集用`.pnepack`にできますが、完成版`.pne`には書き出せません。

`asset_manifest.json`は手書きしません。Tauriが台本の参照と実際のファイルから生成します。
